# 附录 B　术语表

表格按中文名的拼音顺序排列，从 b 排到 z，英文写在括号里。读代码、翻论文、或者想起某一页却记不清那个词的时候，先在这里花十秒确认它指什么，再决定要不要回到正文找细节。每条只给一句够用的解释，作用像是地图上的地名标注，能让你判断自己站在哪一块，不负责讲清路怎么走。同一个概念在文献里有好几种英文写法时，这里收的是本书正文一直在用的那个。

| 术语（英文） | 一句话解释 |
| --- | --- |
| 白化（whitening） | 对表征做线性变换，使各维方差为一且互不相关。 |
| 表征（representation） | 把图像或文本映射成向量，只保留对下游任务有用的差异。 |
| 柏拉图式表征假设（Platonic Representation Hypothesis） | 猜想不同模型会收敛到同一套世界表征，只差一个旋转。 |
| 重建（reconstruction） | 要求模型把被遮住或压缩掉的像素原样还原出来。 |
| 冻结编码器（frozen encoder） | 参数不再更新的编码器，用来检验它原有的表征质量。 |
| 对比学习（contrastive learning） | 拉近同一样本的两个视图，同时把其他样本推远。 |
| 负样本（negative sample） | 与锚点无关的样本，被推开以撑起表征空间。 |
| 干扰变量（nuisance） | 同场景不同观测各自携带的私有因素，如视角、措辞。 |
| 各向同性高斯（isotropic Gaussian） | 各方向方差相同的高斯分布，形状是正球而不是椭球。 |
| 轨迹推演（rollout） | 在世界模型内部连续预测多步，不与环境真正交互。 |
| 好视图（good view） | 同一场景的两次独立观测，只共享场景本身。 |
| 互近邻（mutual k-NN） | 两种表征下互为近邻的样本比例，无需拟合映射。 |
| 坏视图（bad view） | 同一次观测的两种损坏，如裁剪、掩码、加噪。 |
| 监督（supervised learning） | 靠人工标注的标签学习，标签决定模型学到什么。 |
| 可证明的 JEPA（LeJEPA） | 用切片高斯正则在理论上保证不塌缩的训练目标。 |
| 拉普拉斯矩阵（Laplacian matrix） | 图上的差分算子，它的特征向量给出节点上的平滑模式。 |
| 联合嵌入预测架构（JEPA） | 把两种观察各压成向量，再从一个向量预测另一个。 |
| 零样本（zero-shot） | 在完全没见过的类别或任务上直接评测，不做微调。 |
| 模型拼接（model stitching） | 把两个模型的前后半段接起来，中间插一层线性映射。 |
| 模型预测控制（MPC） | 每步只执行规划的第一段动作，然后重新观测再规划。 |
| 目标编码器（target encoder） | 只提供预测目标的编码器，参数靠滑动平均缓慢跟随。 |
| 能量模型（energy-based model） | 用标量能量给配置打分，能量低表示更合理。 |
| 配分函数（partition function） | 能量模型归一化用的积分，通常算不出来。 |
| 谱间隙（spectral gap） | 第 k 与第 k+1 个特征值之差，决定嵌入是否唯一。 |
| 谱嵌入（spectral embedding） | 取图的前几个特征向量当坐标，把节点放进低维空间。 |
| 切片高斯正则（SIGReg） | 把嵌入投影到许多随机方向，逐条逼它们接近标准正态。 |
| 上下文编码器（context encoder） | 只看未被遮住部分的编码器，它要预测目标块的表征。 |
| 生成式世界模型（generative world model） | 直接预测下一帧像素的世界模型，输出能给人看。 |
| 时空小块（tubelet） | 视频里跨若干帧的一小段立方体，当作一个词元处理。 |
| 世界模型（world model） | 给定当前状态与动作，预测下一状态的内部模拟器。 |
| 视觉 Transformer（ViT） | 把图像切成小块当词元的 Transformer，本书的骨干网络。 |
| 视频 JEPA（V-JEPA） | 在视频时空块上做表征预测，能学到运动与接触的直觉。 |
| 视图（view） | 同一底层内容经过一次变换后得到的观测版本。 |
| 首位命中率（R@1） | 检索结果第一条就是正确答案的样本比例。 |
| 塌缩（collapse） | 所有输入被编成同一个向量，表征不再携带信息。 |
| 探针（probe） | 冻结表征后训练的小模型，只用来读出某一类信息。 |
| 停梯度（stop-gradient） | 前向照常计算，反向不把梯度传给这一侧。 |
| 图像 JEPA（I-JEPA） | 在单张图的块之间做表征预测，不需要负样本与像素。 |
| 图像描述评测指标（CIDEr） | 用 n 元组重合度给机器写的图注打分，越高越像人写。 |
| 图文对比模型（CLIP） | 用四亿图文对做对比学习，让图像与文本向量可比。 |
| 推理（inference） | 固定参数后找最合适的输出，等同于在能量面上找低点。 |
| 维度塌缩（dimensional collapse） | 表征没变成常数，但挤在很低的子空间里，维度被浪费。 |
| 温度（temperature） | softmax 前的缩放系数，越小分布越尖，对比越狠。 |
| 线性探测（linear probing） | 冻结编码器后只训一层线性分类器，用来量表征好坏。 |
| 信息噪声对比估计（InfoNCE） | 把正样本当正确类别做分类的对比损失。 |
| 掩码建模（masked modeling） | 遮住输入的一部分，让模型从剩余部分推断被遮内容。 |
| 预测器（predictor） | 接在上下文编码器后面的小网络，负责跨位置预测表征。 |
| 真匹配排名比例（FOSCTTM） | 正确配对排在随机配对前面的比例，越低说明对齐越好。 |
| 蒸馏（distillation） | 让学生模型模仿教师模型的输出，把它的能力搬过来。 |
| 正交 Procrustes（orthogonal Procrustes） | 求一个正交矩阵把一组点最优地对上另一组，有闭式解。 |
| 正样本（positive sample） | 被判定为语义相同的两个观测，训练时要求它们靠近。 |
| 指数滑动平均（EMA） | 用衰减系数把历史权重混进当前权重，得到更稳的副本。 |
| 中心化核对齐（CKA） | 比较两个表征的相似度矩阵，取值零到一，对缩放不敏感。 |
| 自监督（self-supervised） | 标签从数据自身造出来，不需要人工标注。 |
| 自蒸馏视觉模型（DINOv2） | 用自蒸馏训练的视觉骨干，特征常被直接当作通用表征。 |

有少数词在书里的用法比通行说法窄一些，比如推理在能量模型的语境下专指最小化能量，好视图与坏视图也只在讨论正样本分布时才有意义。表格给的是全书统一的口径，读到别处发现轻微不一致，以那一章上下文为准。若某条解释读完仍然抽象，多半说明它属于需要看公式的那一类，附录 A 里有对应的几何解释，第 14 章与第 15 章则把这些词写成了命题与定理。
