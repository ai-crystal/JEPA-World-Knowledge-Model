# 进阶篇

### 同一张世界的地图·进阶篇

联合嵌入预测的训练与工程

作者：Dr. Dezeming　·　2026 年 · 第一版

同一个网络、同一批数据，只改动“什么算作正样本”，对齐水平可以差出一倍；白化之后还要管形状，SIGReg 把这件事变成一条可以证明的目标函数。这一册讲的是工程：目标函数怎么选，超参怎么配，塌缩怎么早发现，视图该怎么构造，指标该怎么读。
