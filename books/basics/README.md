# 入门篇

### 同一张世界的地图·入门篇

从语言模型到 JEPA 的第一课

作者：Dr. Dezeming　·　2026 年 · 第一版

语言模型把整个互联网读了一遍，却仍然说不清一个杯子放在桌沿时会不会掉下去。它缺的不是参数，而是关于世界的那份表征。JEPA 给出的答案很克制：不去重建像素，只在表征空间里预测。这一册从输入法联想讲到世界模型，把这条路上的每个概念都摊开讲一遍，不预设任何自监督学习的基础。
